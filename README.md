# Advanced-Todo-App

A modern and minimal task management app built with **Next.js (React framework)** and **Tailwind CSS**.  
This project allows users to add, delete, and mark tasks as complete — all stored locally in the browser.  
It also includes informative pages like **About** and **Contact** for a full app experience.

---

## Features

- **Home page** – clean introduction and navigation  
- **Task page** – add, delete, and mark tasks as done  
- **Contact page** – simple contact form with name, email, and message fields  
- **About page** – brief overview of the app  
- **Local Storage support** – data stays even after reloading  
- **Tailwind CSS** styling for responsive, modern UI

---

## Tech Stack

- **Next.js** – React framework for building modern web apps  
- **React Hooks (useState, useEffect)** – for managing tasks  
- **Tailwind CSS** – utility-first CSS framework  
- **LocalStorage API** – for saving tasks locally  

---

## Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/DenizShayan/Advanced-Todo-App

# Go to the project folder
cd Advanced-Todo-App

# Install dependencies
npm install

# Run the development server
npm run dev
